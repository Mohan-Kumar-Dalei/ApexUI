## Why ApexUI

- **113 components** across backgrounds, cards, text effects, navigation, buttons, interactive UI, AI interfaces, loaders and maps, with new ones added regularly.
- **Real 3D, still light.** Three.js and WebGL components (Galaxy 3D, Warp Tunnel, Distortion Image, Liquid Blob 3D, Particle Morph, Retro Grid 3D, Gooey Nav) use one small shader each, cap the pixel ratio, pause when off screen and free the GPU on unmount.
- **AI-ready UI.** Chat, prompt box with model picker, thinking state, streaming response and five voice assistant visuals.
- **You own the code.** The CLI copies plain `.jsx` files into your project. No runtime package, no lock-in.
- **Every docs page** has a live preview, a playground for the props, a Desktop / Tablet / Mobile view, the full props table, and a ready prompt you can paste into ChatGPT or Claude.
- **Built to feel smooth.** Transform and opacity animations, reduced-motion support, and mouse, touch and keyboard input.

## Quick start

```bash
# 1. add the CLI
npm install apex-ui-kit

# 2. add any component by name
npx apex-ui-kit add liquid-blob-3d
```

The CLI asks where to put the files, installs what the component needs, and copies it to `ApexUI-Kit/<ComponentName>/`.

```jsx
import LiquidBlob3D from "./ApexUI-Kit/LiquidBlob3D/LiquidBlob3D.jsx";

export default function Hero() {
  return <LiquidBlob3D colors={["#a3e635", "#22d3ee", "#a78bfa"]} />;
}
```

Needs React 18+ and Tailwind CSS (v4 recommended). Setup guides: [React](https://apex-ui.in/components/docs/getting-started/installation/react-setup) · [Tailwind](https://apex-ui.in/components/docs/getting-started/installation/tailwind-setup) · [CLI](https://apex-ui.in/components/docs/getting-started/installation/apexui-cli).

## Run the docs site locally

```bash
git clone https://github.com/Mohan-Kumar-Dalei/ApexUI.git
cd ApexUI
npm install
npm run dev
```

```
src/
├── components/MainUI/ApexUI-Kit/   # the component library (what the CLI installs)
└── site/                           # the documentation website
    ├── config/navigation.js        # one list drives the sidebar, search, gallery and routes
    ├── content/components/         # one *Doc.jsx page per component
    ├── docs/                       # page building blocks (ComponentDoc, playground controls, device preview)
    └── layout/                     # navbar, sidebar, search, page loader
```

**Adding a component:** put it in `src/components/MainUI/ApexUI-Kit/<Name>/<Name>.jsx`, add `src/site/content/components/<Name>Doc.jsx`, then add one entry to `componentPages` in `navigation.js`. The sidebar, search and gallery pick it up.
